# ADR 0021: Canonical Nukhbapay project naming

Date: 12 November 2026. Status: accepted within the owner's bounded naming authorization.

Use **Nukhbapay** for display and **nukhbapay** for technical project names. Coordinate private workspace scopes/imports, Python module paths, current prose, example schema IDs and local synthetic audiences in the existing repository. Use pinned pnpm with offline metadata regeneration, frozen installation and scripts disabled; preserve all third-party dependency versions and integrity records.

Registered migration source, SQL privilege/bootstrap recipes, actual database/schema/roles/RLS/GUC contracts, prior ADRs and verification/handover evidence are retained. Physical checkout and Compose storage locators are compatibility exceptions, not current display branding. Prior ADRs' old package paths/names describe their historical snapshots; use canonical source names for current commands. See [the naming register](../naming-standardization.md) for classification, exact identifiers, source paths and controlled resource-transition procedures.

Local synthetic audiences have exact canonical values with explicit negative tests for historical spellings. No trust aliases, real Auth0 configuration, schema/privilege changes, operational MFA, accepted approvals, APPLY, endpoint or financial change is approved. External resource transitions and further bricks still require their existing approvals.
